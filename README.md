# Address_Book_System

## Description:

* Address Book System is a Java-based application that manages contact information, including first name, last name, address, city, state, ZIP code, phone number, and email.

* The system allows users to add, edit, delete, search, and sort contacts, while supporting multiple contacts and multiple address books.

## Use Cases:

### Use Case 1: Create Contact in Address Book
Contacts can be created with the respective attributes in the address book system

### Use Case 2: Add Contact to Address Book
Accepts creation of new contacts and adds them to the address book

### Use Case 3: Edit Contact using Name
Allows users to search for an existing contact by name and update their personal and address details
If the contact is not found, no editing is performed.

### Use Case 4: Delete Contact by Name
Allows users to delete an existing contact by searching for the person's name through the console. 
If the contact is not found, no deletion is performed.

### Use Case 5: Manage multiple contacts
Enables users to add and maintain multiple contacts in an address book using a Java Collection (ArrayList)

### Use Case 6: Manage Multiple Address Books
Enables users to create multiple uniquely named address books and manage contacts separately in each address book
